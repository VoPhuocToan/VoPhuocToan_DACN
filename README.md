# VoPhuocToan_DACN  
🎓 Đồ án chuyên ngành – Hệ thống Website bán thực phẩm chức năng tích hợp Chatbot AI tư vấn khách hàng

---

## 📌 Giới thiệu dự án
Dự án **VoPhuocToan_DACN** là một hệ thống website bán **thực phẩm chức năng** được xây dựng theo mô hình **Web Full-Stack**, tích hợp **Chatbot AI** nhằm hỗ trợ tư vấn sản phẩm cho khách hàng một cách nhanh chóng và chính xác.

Hệ thống cho phép người dùng:
- Xem và tìm kiếm sản phẩm
- Xem chi tiết thông tin sản phẩm
- Quản lý giỏ hàng và đặt hàng
- Nhận tư vấn sản phẩm thông qua chatbot AI

Dự án được thực hiện là **Đồ án chuyên ngành Công nghệ thông tin**.

---

## 🛠️ Công nghệ sử dụng

### 🔹 Frontend
- HTML, CSS, JavaScript  
- ReactJS  

### 🔹 Backend
- NodeJS  
- ExpressJS  
- RESTful API  

### 🔹 Cơ sở dữ liệu
- MongoDB(NóQL)  

### 🔹 Khác
- Git & GitHub  
- Chatbot AI tích hợp hỗ trợ tư vấn khách hàng
